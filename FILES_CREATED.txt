================================================================================
  📊 WHAT WORKS & HOW
================================================================================

FLOW:
1. User opens Vercel URL in browser
2. React frontend loads (hosted on Vercel)
3. Frontend connects to Railway backend
4. Backend is connected to WhatsApp via QR code
5. User selects group + time period
6. Backend fetches messages from selected group
7. Messages sent to Claude API for summarization
8. AI-generated summary returned to frontend
9. Beautiful summary displayed to user
10. Messages NOT stored anywhere

AUTO-DEPLOYMENT:
1. You push code to GitHub
2. GitHub webhook triggers both:
   → Vercel auto-builds & deploys frontend
   → Railway auto-builds & deploys backend
3. Both deployments happen in parallel
4. No manual deployment needed

SECURITY:
- Messages not stored (generated then deleted)
- QR-code authentication (no passwords)
- API keys stored only on backend (not exposed)
- All communication encrypted (HTTPS)
